# Hyakki: Night Parade, playtest builds

These are early playtest builds of **Hyakki: Night Parade**, a dark-fantasy action RPG set in late Heian Japan.

This repo holds builds only. The source code is private.

## Download

Get the latest build from [**Releases**](../../releases/latest).

- **macOS:** `Hyakki_Gorge_macOS.zip` runs on Apple Silicon and Intel Macs.
- **Windows:** `Hyakki_Gorge_Windows.zip` is for 64-bit Windows.

## First launch

**macOS.** The app isn't signed yet, so macOS blocks it the first time.

1. Unzip it.
2. Right-click **Hyakki Gorge**, choose **Open**, then **Open** again.

If it's still blocked, go to **System Settings → Privacy & Security → Open Anyway**.

**Windows.** Unzip the whole folder and run `Hyakki Gorge.exe`.

If SmartScreen appears, click **More info → Run anyway**.

## Controls

| Action | Keyboard / mouse | Gamepad |
|---|---|---|
| Move | Click, or hold to follow the cursor, or WASD | Left stick |
| Zoom | Scroll wheel | Right stick |
| Interact (ferry, bell) | E | A |
| Switch art style (Natural / Painterly / Ink & Paint) | T | Select / View |
| Day / night | N | Y |
| Help / quit | Esc | Start |

## What this build is

It's a walkthrough of the first Act 1 zone, the **Kazurabashi Gorge**. There's no combat yet.

Walk from the relay station across the vine bridge, down the switchbacks, over the rope ferry and the log bridge, to the waterfall basin.

The art is work in progress. Trees and characters are placeholders.
